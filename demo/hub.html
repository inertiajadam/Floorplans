The plan tracer

Trace a floor plan once and export the geometry. Changing a map is not a support ticket.

  • Load a floor plan image, or press “+ Rectangle” to start without one
  • Click to drop points, Enter to close a suite, drag the handles to adjust
  • The export is the exact JSON the platform consumes — no conversion step
  • Re-tracing a floor later keeps every suite's availability, matched by number

What is not built yet

Everything above is real and runs. The client side is done; the server side of making this a standalone platform is not. In the order I would do it:

  1. The public API. blocking These demos read the map from a static file. The contract is fixed and exercised by the test suite's mock server, but nothing real serves it yet.
  2. Domain allowlisting. blocking Without it, anyone can embed a map and any site can generate leads against one. The refusal path and its wording already exist on the client side.
  3. Platform tenancy. Its own accounts, communities and maps, replacing the coupling to the Seniors Places listing database.
  4. Lead forwarding. Capture, then deliver on to Seniors Places, an operator's CRM webhook, or email.
  5. Floorplanner import. You already produce the 3D renderings there, so the geometry for real communities already exists — importing it removes tracing entirely for those.
  6. Scheduled PMS sync. The adapter and reconciliation are built and tested; the nightly job and its alarm are not. The alarm matters more than the job: a feed that stops returning rows looks exactly like success while the map freezes on stale data.
Willow Creek Senior Living is a synthetic 61-unit campus generated by scripts/build-demo.mjs — no real availability, rates or residents. Lead submission in these demos is captured to the browser console instead of a server. The PointClickCare and Floorplanner integrations are written against unverified API shapes, because both vendors' documentation is unreachable from the build environment; every assumption is isolated in config and flagged as such.
